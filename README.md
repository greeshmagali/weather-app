# Weather Application

A frontend web application that provides real-time weather information for any city.
This project demonstrates API integration, asynchronous JavaScript, and dynamic UI updates.

---

## Technologies Used

* **HTML5** – Structuring the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Application logic and API handling
* **OpenWeatherMap API** – Fetching real-time weather data

---

## Features

* Search weather by city name
* Display:

  * Temperature
  * Weather conditions
  * Humidity
* Real-time weather data fetched from API
* Responsive design for mobile and desktop devices

---

## Development Process

1. Designed the application layout using HTML
2. Styled the UI with CSS for clarity and responsiveness
3. Integrated the OpenWeatherMap API to fetch weather data
4. Dynamically updated the UI based on API responses
5. Handled basic error scenarios such as invalid city names
